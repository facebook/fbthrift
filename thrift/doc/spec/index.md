# Specification

The Thrift specification is the behavior every Thrift implementation shares, so that clients and
servers written in different languages work together. It is documented with the parts of Thrift it
describes:

* [Interface Definition Language](../idl/index.md)
* [Object Model](../object-model/index.md)
* [Features](../features/index.md)

[Conformance tests](../contributions/conformance/index.md) allow implementations to be compared.

## Implementation Compatibility

Implementations also share behavior that the specification doesn't define. See
[Implementation Compatibility](compatibility/index.md).
