# Nonconforming entries are tests that are expected to fail. These are named
# the same way as the test harness, e.g.:
#
#    <category>/<suite>/<case>.<test>
#
# `<category>` can be a language e.g. `cpp2` or a language plus config options
# e.g. `rust[client=cpp,protocol=binary]`.
#
# Entries support globs with `*` to match any run of characters and `?` to
# match any single one. e.g. `python/ThriftRPCServerTest/Bidi*`.
#
# When matching config options `*` admits any options the line doesn't list, so
# `rust[client=cpp,*]/...` matchs any configuration of `rust` with the `cpp`
# client.
#
# The tests listed here *must* fail. If a test listed here passes that's a
# test failure because it now conforms. The line should be removed if it passes.
